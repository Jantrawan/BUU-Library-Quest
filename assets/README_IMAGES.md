# โฟลเดอร์ภาพและกราฟิก (Assets Directory)

## 1. ภาพภายในเกมต้นฉบับสร้างอย่างไร?
ในโค้ดต้นฉบับของเกม **BUU Library Quest** ไม่ได้ใช้ไฟล์รูปภาพภายนอก (`.png` / `.jpg` / `.svg`) แต่อาศัยการวาดภาพแบบ **Procedural Vector Graphics ผ่าน HTML5 Canvas 2D API** ทั้งหมด ได้แก่:
1. **ตัวละครหลัก "น้อง MEEDEE"** (`js/meedee.js` -> ฟังก์ชัน `drawMeedee()`):
   - วาดหมวกกันน็อกสีม่วง 3D พร้อมแถบสีเทาเข้มด้านบน กรอบหน้ากากสีเงิน หูฟังและเขาสีเหลือง ปลอกคอ/ข้อมือ/ข้อเท้าสีเหลือง รองเท้าสีขาว หนังสือเปิดสีม่วง และแว่นขยายนักสืบในด่านที่ 1
   - รองรับแอนิเมชัน 7 ท่าทาง (`idle`, `walk`, `run`, `jump`, `fall`, `happy`, `hurt`) และสีหน้า 3 อารมณ์ (`normal`, `happy`, `sad` พร้อมน้ำตาไหล)
2. **ฉากหลัง 4 ธีมหลัก** (`js/game.js` -> ฟังก์ชัน `drawThemeBackground()`):
   - **ธีม `opac` (OPAC Detective):** หน้าต่างมู่ลี่แสงจันทร์ กระดานสืบสวนไม้ก๊อกพร้อมหมุดและด้ายแดง
   - **ธีม `explorer` (Library Explorer):** หน้าต่างโค้งรับแสงแดด ชั้นหนังสือไม้ โซฟาสีชมพู และโคมไฟอ่านหนังสือ
   - **ธีม `haunted` (Smart Study Challenge):** ห้องสมุดยามค่ำคืน พระจันทร์เต็มดวง เทียนไข และผีน้อยสีขาวลอยไปมา
   - **ธีม `master` (The Library Master):** เสาและชั้นหนังสือสีทองอร่าม เครื่องสืบค้น OPAC ลูกโลก และหนังสือเวทมนตร์ลอยได้
3. **ไอเทมและสิ่งกีดขวางในฉาก** (`js/game.js` -> ฟังก์ชัน `renderGameWorld()`):
   - หนังสือคำถามเรืองแสงสีทอง, ธง Checkpoint, หนอนกระดึ๊บสีเขียว 4 ปล้อง และเคาน์เตอร์ยืม-คืนพร้อมบรรณารักษ์นกฮูก
4. **ภาพประกอบคำถาม (Quiz Illustration):**
   - รองรับการใส่ลิงก์ URL รูปภาพ หรืออัปโหลดไฟล์ภาพจากเครื่อง (แปลงเป็น Base64 Data URL เก็บใน `localStorage`) ผ่านหน้า **Admin Dashboard**

## 2. หากต้องการนำไฟล์รูปภาพจริงมาวางใช้งาน
สามารถนำไฟล์ภาพมาวางในโฟลเดอร์ `assets/` นี้ (เช่น `meedee.png`, `owl_librarian.png`, `book_icon.png`) แล้วโหลดด้วย `new Image()` ใน `js/meedee.js` หรือ `js/game.js` ได้ทันที
